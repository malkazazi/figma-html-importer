HTML → Figma Importer — Quick Install (no terminal needed)
===========================================================

You install two things: a Figma plugin and a Chrome extension.
Everything is pre-built — you do NOT need Node, npm, or a terminal.

------------------------------------------------------------
1) FIGMA PLUGIN  (requires the Figma DESKTOP app, not the web version)
------------------------------------------------------------
1. Open the Figma desktop app and open any design file.
2. Top menu → Plugins → Development → "Import plugin from manifest…"
3. Select the file:  plugin/manifest.json  (inside this folder)
4. It now lives under Plugins → Development → "HTML Importer (Local)".

------------------------------------------------------------
2) CHROME EXTENSION  (for capturing pages)
------------------------------------------------------------
1. Go to  chrome://extensions  in Chrome.
2. Turn on "Developer mode" (top-right toggle).
3. Click "Load unpacked".
4. Select the  extension/  folder (inside this folder).

------------------------------------------------------------
HOW TO USE IT
------------------------------------------------------------
1. Open a page in Chrome, click the extension icon, pick your
   breakpoints, click Capture. You get a .fhtml file (or it copies
   to your clipboard).
2. In Figma, run the "HTML Importer (Local)" plugin. Drop the .fhtml
   file in, or paste the clipboard, and click Import.

------------------------------------------------------------
GETTING UPDATES  (update in place — no re-downloading by hand)
------------------------------------------------------------
When a new version ships, update this folder in place:

  macOS:
    • Double-click  update-macos.command  in this folder.
    • First time only: if macOS says it "cannot verify the developer,"
      right-click update-macos.command → "Open" → "Open" once.
      (Prefer the terminal? Run:  bash update-macos.command )

  Windows:
    • Double-click  update-windows.bat  in this folder.
    • If SmartScreen warns, click "More info" → "Run anyway".

It downloads the latest version and overwrites these files for you.
Then just refresh both apps:
  • Chrome: open chrome://extensions and click the reload (↻) icon
    on "Figma Multi-Breakpoint Capture".
  • Figma:  just re-run the "HTML Importer (Local)" plugin.

Keep this folder where it is — Chrome and Figma load from this exact
location, so updating in place is what makes the refresh work.

Want to know when a new version is out? On the GitHub page
(https://github.com/malkazazi/figma-html-importer) click "Watch" →
"Custom" → check "Releases" → Apply. GitHub will email you each time a
new version ships, so you know when to run the updater.

Full details and limitations are in README.md.
